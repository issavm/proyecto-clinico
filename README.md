# Análisis de Dataset Clínico Simulado

Este proyecto contiene el análisis exploratorio y visualización de un dataset clínico de 200 pacientes. Forma parte de la práctica de "Git, GitHub y Reproducibilidad".

## Estructura del Proyecto
* `data/`: Contiene el archivo original `dataset_clinico_simulado_200.csv`.
* `src/`: Contiene el script principal de Python (`analysis.py`).
* `outputs/resultados/`: Carpeta donde se exportan automáticamente las gráficas generadas.

## Requisitos
Para instalar las dependencias necesarias, ejecuta:
`pip install -r requirements.txt`

## Cómo ejecutar el análisis
1. Activa tu entorno virtual.
2. Ejecuta el script principal desde la raíz del proyecto:
`python src/analysis.py`

Las gráficas se guardarán automáticamente en la carpeta de resultados.
