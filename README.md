# Análisis de Dataset Clínico Simulado
Este proyecto consiste en el análisis exploratorio y visualización de registros médicos de pacientes, desarrollado como parte de la práctica enfocada en Git, GitHub y Reproducibilidad.

## Dataset
* **Nombre del dataset:** `dataset_clinico_simulado_200.csv`
* **Fuente:** Datos simulados proporcionados para la práctica escolar de análisis clínico.
* **Descripción breve:** Conjunto de datos que contiene 200 registros de pacientes, incluyendo variables como texto clínico descriptivo, edad, género, tipo de afección y nivel de gravedad.

## Objetivo
Automatizar la limpieza de datos, crear clasificaciones demográficas (grupos de edad) y ejecutar un análisis exploratorio para descubrir patrones entre las características de los pacientes y la gravedad de sus afecciones, garantizando la total reproducibilidad del código.

## Requisitos
Para ejecutar este proyecto se requiere **Python 3** y las dependencias específicas incluidas en el archivo `requirements.txt` (pandas y matplotlib).
